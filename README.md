# Semantic_Code_Search
Semantic_Code_Search est un classique très fort pour un hackathon ML/IR/NLP : il combine embeddings multilingues code/texte, retrieval dense (FAISS), reranking, évaluation IR, LLM explicatif, et garde-fous. Il est parfaitement cadré pour scorer haut sur la grille (embeddings + contrastive + FAISS + Transformers + IR metrics + produit).
