Formules Mathématiques

MRR@10

MRR = (1/|Q|) × Σ(1/ranki)
Où ranki est la position du document pertinent pour la requête i.

Recall@10

Recall = |Trouvés| / |Total|
Proportion de documents pertinents retrouvés dans le top 10.

nDCG@10

nDCG = DCG / IDCG
Mesure la qualité du classement avec pénalisation logarithmique.
